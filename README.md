# HTML & CSS Learning Page

A colourful introductory page combining headings, lists, a sample form, and a timetable.

## ✨ Highlights

- HTML elements and a separate `style.css` file.
- Practice with class selectors and page styling.

## 🚀 Getting started

Download or clone the repository, then open [index.html](index.html) in a web browser. No package installation or build step is required.

## 🗂️ Repository guide

- [index.html](index.html)
- [style.css](style.css)

## 📝 Project notes

An early learning exercise that includes legacy HTML such as `marquee`; the form is static.
